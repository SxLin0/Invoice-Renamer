# 🐱 发票重命名工具

**一键批量上传 PDF 发票 → 自动识别金额 → 重命名为 `金额.pdf`（如 `40.00.pdf`）**  
无需安装任何桌面软件，浏览器搞定！

---

## ✨ 主要功能

* 拖拽多文件上传
* 多规则 OCR 提取金额（小写、价税合计等）
* 已重命名文件智能跳过
* 单文件下载 & 一键清空

---

## 🚀 使用步骤

1. **安装依赖**  
```bash
pip install flask pdfplumber
```

2. **启动服务**  
```bash
python app.py
```

3. **打开浏览器**  
```
http://127.0.0.1:5000
```

4. **把发票拖进提示区域** → 秒变 `金额.pdf`

---

## 📁 目录说明

* `app.py` – Flask 后端
* `templates/index.html` – 萌猫前端
* `uploads/` – 临时上传（自动创建）
* `processed/` – 重命名后文件（自动创建）
* `icon.jpg` – 猫头像（可替换任意方形图片）

---

## 🔍 金额提取规则

1. 小写：¥**xx.xx**  
2. 价税合计**xx.xx  
3. 直接出现 **xx.xx**

未匹配 → 提示“未找到金额”。

---

## ⚙️ 配置项

| 配置名               | 默认值      | 含义           |
| -------------------- | ----------- | -------------- |
| `UPLOAD_FOLDER`      | `uploads`   | 临时上传目录   |
| `PROCESSED_FOLDER`   | `processed` | 重命名输出目录 |
| `MAX_CONTENT_LENGTH` | 16 MB       | 单次上传上限   |

---

## 🛠️ 接口列表（开发调试）

| 方法 | 路径                 | 功能                     |
| ---- | -------------------- | ------------------------ |
| GET  | `/`                  | 首页                     |
| POST | `/upload`            | 批量上传，返回 JSON 结果 |
| GET  | `/download/<文件名>` | 下载已处理文件           |
| GET  | `/processed-files`   | 列出已处理文件           |
| POST | `/clear-files`       | 清空所有临时及输出文件   |
